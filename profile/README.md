# 信工实验室（XXGCIELab）

新乡工程学院的学生开发者组织。我们在课程之外以真实项目练习软件开发的完整流程：需求拆解、协议分析、版本管理、代码评审与发布运维，并把过程中的结论沉淀成文档。

XXGCIELab 取自 XinXiang GongCheng（新乡工程学院）与 Information Engineering Lab 的组合，中文名信工实验室。

## 工作方向

- 校园工具：围绕教务系统、日常学习等场景开发实用工具，把重复操作交给程序
- 系统工程实践：前后端分离、接口设计、数据库建模到部署运维的完整链路
- 协作规范：以 Git 与 GitHub 为协作平台，练习分支管理、Issue 跟踪与 Release 发布
